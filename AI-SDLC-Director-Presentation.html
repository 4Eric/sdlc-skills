Answering "Do Skills Limit AI?" — Constraints & Context, Not Tutorials

Why 1,500-Line "Tutorial Skills" Degrade Frontier Models (-30% to -45% Accuracy)

  • 1. Reasoning Suppression: Dictating step-by-step boilerplate overrides native RL chain-of-thought planning.
  • 2. Syntax Ossification: Pasting 2022 code snippets forces the LLM to mimic stale patterns instead of React 19 / TS 5 weights.
  • 3. Context Rot ("Lost in the Middle"): 12,000+ tokens of prose fluff dilute attention on actual repo contracts.

The 5 High-Leverage Pillars of a <100-Line Enterprise SKILL.md

Pillar What We Encode (Zero Fluff) Stripped Out
1. Tribal Domain Quirks Non-obvious API edge cases & required fallback chains Generic REST / async tutorials
2. Executable Tools & MCP Exact repo CLI commands & internal MCP tool schemas How npm or git works
3. Security Red Lines Banned APIs, scope locks & assertion integrity rules Vague "write clean code" prose
4. Outcome Exit-0 Gates Binary checks: npm test && npm run build == 0 + ARIA roles Prescribing private variable names
5. Disjoint File Scopes Phase 2 contract lock + non-overlapping subagent write paths Uncoordinated multi-agent edits

05 // ENTERPRISE HARDENING & PRODUCTION SAFETY CONTROLS (REM-01 – REM-04) SOLVING THE 4 HARDEST ENTERPRISE FAILURE MODES

Built for 8-Year-Old Brownfield Monoliths & Hostile Threat Models

1. Brownfield Monolith Ratchet (REM-01)

diff-cover ≥ 85%

Problem: Legacy revenue monoliths have 15–30% baseline coverage; an 85% global gate deadlocks every PR on Day 1.

  • Step 0 "Golden Master" Characterization Subagent (flash): Automatically snapshots existing input/output behavior in src/__tests__/characterization/ before Phase 3 edits legacy files.
  • Differential Gate: Enforces diff-cover ≥ 85% on modified/added lines only + tsc-files & git-diff ESLint zero-warning ratchet.

2. Anti-Slopsquatting Supply-Chain Lock (REM-02)

2-Stage Lock

Problem: LLMs hallucinate plausible package names that attackers register with malicious postinstall scripts.

  • Stage 1 (Phase 3 Manifest Lock): PreToolUse locks package.json / pom.xml read-only and blocks unapproved npm/pip install calls.
  • Stage 2 (Phase 6 Provenance Gate): socket-cli ci --strict + verify-package-provenance.mjs enforces ≥30-day registry age, ≥5,000 wk downloads, --ignore-scripts, and Sigstore attestation.

3. MCP Indirect Prompt Injection Airlock (REM-03)

OWASP LLM01 Defense

Problem: Malicious instructions hidden in Jira tickets, GitHub issues, or Sentry logs hijack agent tool calls to exfiltrate secrets.

  • flash_lite Input Sanitization Airlock: Strips hidden Unicode/HTML and wraps external MCP payloads in <untrusted_external_content instruction_authority="NONE">.
  • Taint-Guard Hook (TAINTED_EXTERNAL_INPUT=true): Deterministically blocks outbound curl/wget/ssh and blocks reads to .env* or credentials during tainted turns (breaks the "Lethal Trifecta").

4. Expand-and-Contract DB Rollback Gate (REM-04)

<60s Safe Rollback

Problem: Phase 7's <60s container rollback causes a P0 outage if the release dropped or renamed a DB column needed by N-1 pods.

  • Deterministic DDL Linter (squawk + atlas migrate lint): Blocks DROP COLUMN, RENAME, and lock-heavy ALTER in feature PRs.
  • 3-Release Parallel Change: Release $N$ (Additive Expand + Dual-Write) → Release $N+1$ (Backfill & Cutover) → Release $N+2$ (Standalone Contract after AST check proves zero code references).
